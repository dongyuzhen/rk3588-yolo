# 当前完整链路说明

## 总览

```
V4L2 采集（YUYV/CMA dmabuf）
        ↓  dmabuf fd
  YOLO 线程池（NPU 推理）
        ↓  detect_result_group_t（检测框坐标+类别+置信度）
   写出线程（画框 + 编码 + 推流）
        ↓
    RTMP / output.avi
```

三个独立线程通过两个线程安全队列传递数据，全程零 memcpy（除画框阶段）。

---

## 线程 1：采集线程 `captureThreadFunc`

**文件**：`main.cpp`

**流程**：
1. 调用 `g_camera.captureFrame()` → poll + VIDIOC_DQBUF 出队
2. 把 `FramePacket`（含 `dmabuf_fd`、`buffer_index`）压入 `g_captureQueue`
3. 提交异步推理任务到 YOLO 线程池：`npu_pool.submit_task_async(index, dmabuf_fd)`
4. 把 `{FramePacket, future<ProcessResult>}` 压入 `g_processQueue`
5. 循环直到达到 `DEFAULT_FRAME_LIMIT`（默认 500 帧）

**关键参数**：
- 设备：`/dev/video0`
- 分辨率：`640 × 480`
- 格式：`V4L2_PIX_FMT_YUYV`（YUYV422，每像素 2 字节）
- 缓冲区数量：`BUFFER_NUM = 4`（CMA 物理连续内存，由 `/dev/dma_heap/cma` 分配）
- 内存模式：`V4L2_MEMORY_DMABUF`（驱动直接写入 CMA，用户态零拷贝获取 fd）

---

## 线程 2：YOLO 推理线程池 `ThreadPoll`

**文件**：`pool/thread_poll.cpp`、`yolo/yolov5s.cpp`

**线程数**：`PROCESS_THREAD_NUM = 2`，每个线程绑定专属 `Yolov5s` 实例（NPU core 0/1 交替）

**`Yolov5s::inference_image(dmabuf_fd)` 内部流程**：

```
rknn_create_mem → input_mem（640×640×3 RGB，fd 可被 RGA 使用）
rknn_create_mem → output_mems × 3（NPU 输出张量）
rknn_create_mem → mid_mem_（640×480×3 RGB，中间缓冲，避免 CMA 不足问题）

RGA 步骤 A：importbuffer_fd(dmabuf_fd, YUYV_422)
           + importbuffer_fd(mid_mem_->fd, RGB_888)
           → imcvtcolor(YUYV→RGB888，640×480，仅色彩转换)

RGA 步骤 B：importbuffer_fd(mid_mem_->fd, RGB_888)
           + importbuffer_fd(input_mem->fd, RGB_888)
           → imresize(RGB888 640×480 → RGB888 640×640，仅缩放)

rknn_set_io_mem(input_mem)   ← NPU 直接读取 RGA 写好的内存
rknn_run()                   ← NPU 推理
post_process(output_mems)    ← CPU 后处理：NMS + 坐标还原
返回 detect_result_group_t
```

**零拷贝关键点**：
- V4L2 dmabuf fd → RGA src：通过 `importbuffer_fd` 注册，RGA 通过 IOMMU 直接 DMA 访问 CMA
- RGA dst → RKNN input：`rknn_create_mem` 返回的 fd，直接被 RGA 写入，NPU 无需复制

## 线程 3：写出线程 `writeThreadFunc`

**文件**：`main.cpp`

**流程**：

```
g_processQueue.dequeue() 取出 {FramePacket, future}
        ↓
future.get() 等待推理结果（detect_result_group_t）
        ↓
RGA：YUYV_to_BGR_rga(dmabuf_fd → bgr_buf)
  importbuffer_fd(dmabuf_fd, YUYV_422)   ← V4L2 原始帧
  importbuffer_virtualaddr(bgr_buf)       ← CPU 内存（画框用）
  imcvtcolor(YUYV→BGR888)
        ↓
OpenCV：在 BGR Mat 上 rectangle + putText 画检测框
        ↓
RGA：BGR_to_NV12_rga(bgr_buf → nv12_cma)
  importbuffer_virtualaddr(bgr_buf)
  importbuffer_virtualaddr(nv12_cma.addr)
  imcvtcolor(BGR888→NV12)
        ↓
MPP 零拷贝编码：process_frame_fd(nv12_cma.fd())
  mpp_buffer_group_get_external(EXT_DMA)
  mpp_buffer_import_with_tag(nv12 fd)    ← 不 memcpy，编码器直接读 NV12 CMA
  encode_put_frame → encode_get_packet
  write_frame 回调 → RTMP 发送 / AVI 写入
        ↓
g_camera.releaseFrame(packet)            ← QBUF 归还摄像头
```

**NV12 缓冲**：由 `/dev/dma_heap/system`（非 CMA，节省 CMA 内存）分配，大小 = `hor_stride × ver_stride × 3/2`

---

## 内存分配汇总

| 缓冲区 | 大小 | 分配方式 | 用途 |
|--------|------|----------|------|
| V4L2 采集缓冲 × 4 | 640×480×2 = 600KB × 4 = **2.4MB** | `/dev/dma_heap/cma` | 摄像头写入 YUYV |
| RKNN mid_mem × 2 | 640×480×3 = 900KB × 2 = **1.8MB** | rknn_create_mem（内部 DMA heap）| RGA 中间 RGB |
| RKNN input_mem × 2 | 640×640×3 = 1.2MB × 2 = **2.4MB** | rknn_create_mem | NPU 输入 RGB |
| RKNN output_mems | ~2MB | rknn_create_mem | NPU 输出张量 |
| bgr_buf（写线程） | 640×480×3 = **900KB** | std::vector（普通堆） | OpenCV 画框 |
| nv12_cma（写线程） | 640×480×1.5 = **450KB** | `/dev/dma_heap/system` | MPP 编码输入 |
| MPP pkt_buf | ~1MB | MPP 内部 DMA heap | 编码输出 |

**CMA 实际占用**：约 4.2MB（V4L2 采集缓冲），系统 CmaTotal=8MB，CmaFree 约 3.8MB，基本够用。

---

## 队列结构

```
captureThread ──→ [g_processQueue] ──→ writeThread
                  { FramePacket,
                    future<ProcessResult> }
                  （最大深度 32）
```

YOLO 推理在线程池中异步进行，`future.get()` 在写线程里阻塞等待，保证帧序不乱。
